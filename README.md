# Form Permintaan User Operator SIASN Perencanaan

Halaman landing page BKPSDM Kabupaten Kolaka Timur.

## Publikasi
1. Unggah seluruh isi folder `assets/` dari paket ZIP ke repository ini dengan mempertahankan struktur folder.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
5. Setelah deployment selesai, situs akan tersedia di:
   https://kolakatimurbkpsdm-hue.github.io/form-operator-siasn-4/

Tombol formulir mengarah ke https://forms.gle/MyRBCoTxcoNM97UR8.

File `index.html` sudah berada di root repository. Gambar di folder `assets/` perlu diunggah dari paket ZIP agar poster dan pratinjau WhatsApp tampil.
